# Глоссарий

Замороженный контракт. Термины используются во всех артефактах решения без
синонимов и без перевода на другие слова: в BPMN, C4, ERD, OpenAPI, AsyncAPI и
матрице трассировки — те же имена, что здесь.

Колонка «Значение в системе» важнее расшифровки: отраслевой термин и то, как он
применяется в этом решении, — не одно и то же.

## Перелёт и бронирование

| Термин | Расшифровка | Значение в системе |
|---|---|---|
| IROPS | Irregular Operations | Класс событий: отклонение рейса от расписания или маршрута — задержка, отмена, смена времени вылета, борта, терминала. Название класса, не отдельного случая. Конкретный случай называется **сбой** |
| Бронирование | booking | Оплаченная перевозка одного путешественника, состоящая из одного или нескольких сегментов. Единица, к которой привязаны сбой, решение и перебронирование |
| Сегмент | flight segment | Один перелёт одним рейсом из аэропорта в аэропорт. Минимальная единица, по которой приходит статус |
| PNR | Passenger Name Record | Запись бронирования на стороне перевозчика или GDS. Ключ, по которому система запрашивает статус и выпускает перебронирование. Внешний идентификатор, а не источник правды о плане поездки |
| Стыковка | connection | Пара последовательных сегментов, между которыми путешественник пересаживается. Характеризуется запасом времени между фактическим прилётом и вылетом следующего сегмента |
| MCT | Minimum Connecting Time | Минимальное время пересадки для пары «терминал — тип пересадки». Порог годности стыковки. Значение берётся из справочника ограничений — IATA публикует его по 400+ аэропортам, а задают локальные группы аэропортов и комитеты перевозчиков. Системой не вычисляется |
| Misconnect | разрушенная стыковка | Стыковка, у которой запас времени стал меньше MCT. Самостоятельный вид сбоя: оба рейса могут выполняться, а пересадка — не состояться. Детектируется системой, а не приходит от перевозчика |
| Involuntary rebooking | вынужденное перебронирование | Перебронирование по вине перевозчика. Выполняется по существующему PNR, тариф сохраняется, разница тарифа не возникает. Противопоставлено добровольной смене рейса, при которой разница возникает и требует оплаты |
| Багажный тариф | baggage allowance | Норма провоза багажа, привязанная к тарифу билета: число мест, вес, габариты. При подборе альтернативы сравнивается с исходной нормой: снижение означает доплату или оставленный багаж и делает вариант условно годным |
| Транзитная виза | transit visa | Разрешение на пребывание в зоне пересадки страны транзита. Требование определяется гражданством, аэропортом, длительностью пересадки и необходимостью покидать стерильную зону. Отсутствие — жёсткий отказ варианта, без вариантов доплаты |

## Сбой и реакция на него

| Термин | Расшифровка | Значение в системе |
|---|---|---|
| Сбой | disruption | Зафиксированный экземпляр IROPS, затрагивающий конкретное бронирование. Имеет тип, время события, источник, оценку влияния и жизненный цикл до закрытия. Создаётся детекцией внутри системы, извне готовым не приходит |
| Детекция | detection | Установление факта сбоя по потоку статусов: сравнение нового состояния сегмента с планом поездки и с предыдущим известным состоянием |
| Оценка влияния | impact assessment | Разбор последствий сбоя по всему плану поездки: какие стыковки, трансферы, заезды в отель и активности становятся неисполнимыми. Результат — перечень затронутых элементов плана, а не признак «сбой есть» |
| Альтернатива | alternative | Вариант продолжения поездки: другой рейс, другой маршрут, перенос на другую дату. Существует как предложение до момента выпуска билета |
| Проверка ограничений | constraint check | Обязательный шаг: альтернатива проверяется на MCT, багажный тариф, транзитную визу, таймзоны и разницу тарифа **до** показа путешественнику. Результат каждой проверки сохраняется |
| Лестница каналов | channel ladder | Упорядоченная последовательность каналов доставки уведомления. Переход к следующему каналу — по неполучению подтверждения доставки или ответа, а не по отправке |
| Ack-окно | acknowledgement window | Интервал ожидания явного ответа путешественника или организатора. Отсчёт — от сдачи уведомления в первый канал лестницы. По истечении включается авто-политика. Пишется через дефис, строчными |
| Авто-политика | automatic policy | Заданное заранее правило выбора альтернативы без участия человека: применяется при истечении ack-окна. Задаётся на бронирование или на поездку, политика бронирования приоритетнее |
| Эскалация | escalation | Передача сбоя оператору поддержки, когда авто-политика неприменима или перебронирование не удалось. Не является ошибкой процесса |
| Разница тарифа | fare difference | Денежная разница между тарифом альтернативы и исходным тарифом. Положительная требует доплаты и подтверждения плательщика, отрицательная порождает возврат |
| Возврат | refund | Возвращение денег путешественнику: при отрицательной разнице тарифа или при отказе от поездки. Всегда деньги |
| Компенсация | compensation | Только в смысле BPMN: откат ранее выполненного шага процесса — отмена выпущенного билета, возврат брони отеля. Никогда не означает выплату путешественнику. Для денег есть **возврат** и **разница тарифа** |

## Поездка и группа

| Термин | Расшифровка | Значение в системе |
|---|---|---|
| Поездка | trip | Контейнер путешествия: участники, бронирования, план. Поездка с одним участником — не особый случай, а частный |
| План поездки | itinerary | Связанная по времени последовательность элементов поездки: сегменты, трансферы, заезды в отель, активности. Предмет обновления после перебронирования |
| Участие в поездке | trip participation | Связь путешественника с конкретной поездкой. Носитель роли: роль хранится на участии, а не на путешественнике |
| Организатор | trip organizer | Роль на участии: право решать за других участников в пределах выданного мандата и задавать авто-политику поездки |
| Участник | trip participant | Роль на участии: право выдавать и отзывать мандат, отказаться от общего решения для своего бронирования до выпуска билета |
| Мандат организатора | organizer mandate | Разрешение, выданное участником организатору, на выбор альтернативы от его имени. Выдаётся и отзывается участником, действует в границах одной поездки |

## Данные и время

| Термин | Расшифровка | Значение в системе |
|---|---|---|
| Источник статусов | status source | Внешняя система, поставляющая статусы сегментов: агрегатор, push перевозчика или GDS, служебная рассылка. Имеет ранг достоверности, участвующий в разрешении противоречий |
| Время события | `event_at` | Момент, когда изменение произошло у провайдера. Хранится в UTC. Основание для решений |
| Время приёма | `ingest_at` | Момент, когда система получила сообщение. Хранится в UTC. Основание для измерения TTD и для дедупликации, но не для решений |
| Лаг провайдера | provider lag | Разность `ingest_at` и `event_at`. Наблюдаемая величина: характеризует источник, а не систему |
| Свежесть данных | data freshness | Возраст последнего известного статуса сегмента относительно текущего момента. Превышение порога переводит сегмент в состояние неопределённости, а не в состояние «без изменений» |
| Деградация | degradation | Режим работы при недоступности источника или внешнего сервиса: система продолжает работать на оставшихся данных и явно сообщает о снижении полноты. Противопоставлена отказу |
| Локальное время | local time | Время в таймзоне точки события. Формат хранения — UTC плюс отдельное поле таймзоны; локальное время вычисляется при отображении, а не хранится |

## Эксплуатация

| Термин | Расшифровка | Значение в системе |
|---|---|---|
| Алерт | alert | Сигнал в наблюдаемость по превышению порога: лаг источника, доля ошибок внешнего сервиса, сбой без завершающего состояния, запись ПДн с истёкшим сроком удержания. Адресат — служба эксплуатации, не путешественник. Алерт не входит в лестницу каналов и не имеет ack-окна |

## Персональные данные

| Термин | Расшифровка | Значение в системе |
|---|---|---|
| ПДн | персональные данные | Данные субъекта в смысле 152-ФЗ. Широкое понятие: включает имя, контакты, историю поездок |
| Паспортные данные | travel document data | Данные документа, удостоверяющего личность, необходимые для перевозки: тип, номер, срок действия, дата рождения, имя латиницей, страна выдачи. Подмножество ПДн с самым коротким сроком удержания. Гражданство сюда не входит: оно хранится на путешественнике, вне контура ПДн, и сроком удержания не ограничено. Именно к паспортным данным относится P.S. кейса |
| Контур ПДн | PII vault | Изолированное хранилище паспортных данных: отдельная схема, отдельный доступ, отдельный срок удержания. Остальные подсистемы работают со ссылкой на запись, а не с её содержимым |
| Срок удержания | retention TTL | Предельный срок хранения паспортных данных, привязанный к дате завершения поездки. По истечении запись удаляется физически, а не помечается удалённой |
| Журнал доступа | PII access log | Неизменяемая запись каждого обращения к паспортным данным: кто, когда, по какому сбою, с каким обоснованием. Недоступен на чтение и изменение тем, чей доступ фиксирует |

## Слова, которые не используем

Одно понятие — одно слово. Синонимы ниже встречаются в отраслевых текстах и
запрещены в артефактах решения: они порождают ощущение двух разных сущностей там,
где сущность одна.

Запрет касается сообщений, адресованных человеку в поездке. **Алерт** синонимом
уведомления не является: это сигнал в наблюдаемость, адресованный службе
эксплуатации, — см. группу «Эксплуатация».

| Не пишем | Пишем |
|---|---|
| Инцидент, происшествие, проблема | Сбой |
| Пассажир, клиент, юзер | Путешественник |
| Тревога, оповещение | Уведомление |
| Маршрут, итинерарий | План поездки |
| Пересадка (как объект) | Стыковка |
| Компенсация (о деньгах) | Возврат, разница тарифа |
| Задержка данных, отставание | Лаг провайдера |
| Хранилище персональных данных, PII-база | Контур ПДн |
| Групповая поездка (как отдельный тип) | Поездка |
